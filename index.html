OAuth consent screen — typography

This is the screen someone sees when a third‑party app asks for access to their Zendesk account — where they press Allow or Deny. It has had little design attention and still renders in Arial, with five different font sizes. Below is a proposal to put it on the system font and on three steps of the Garden scale.

The type scale

Five sizes down to three, and two weights instead of an unstated mix. Each size is a step on Garden’s existing scale (12 / 14 / 18 / 22 / 26 / 36) rather than a number picked by hand.

Why these three

The grouping is meant to follow what the text is for, rather than decorate:

  • 18px / 600 — the heading, the one question being asked.
  • 14px — everything needed to make the decision: what the app is, and what it will be able to do.
  • 12px — incidental detail: which app is asking, and the “not you?” escape hatch.

The previous five sizes did not map onto a hierarchy. The permissions list was larger than the buttons for no clear reason, and the app description was larger than the permissions it described.

The trade-off worth your opinion

The app description drops from 16px to 14px. That is the sentence explaining what the app does, so making it smaller has a real if small cost. It was taken because 14px is Garden’s standard body size and the text is short, and because keeping it at 16px would leave a fourth size on the page for that one paragraph. Worth a second opinion.

A harder case

A long app name in German, which is roughly the worst this screen has to survive. Both versions hold up, but it is where the heading size shows most.
