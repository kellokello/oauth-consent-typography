# OAuth consent screen — typography proposal

A preview of a proposed typography change to the OAuth consent screen: the
screen someone sees when a third-party app asks for access to their Zendesk
account.

**[View the preview →](https://kellokello.github.io/oauth-consent-typography/)**

The screen currently renders in Arial and had accumulated five font sizes. The
proposal moves it to the system font stack and to three steps of the Zendesk
Garden scale — 18px heading, 14px content, 12px secondary — with two weights.
